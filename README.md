# Tanay Srivastava — Portfolio

A responsive, animated portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. (For best development experience, use VS Code with Live Server.)

## Before publishing
- Replace `hello@example.com` in `index.html` and `script.js` with Tanay's real public email.
- Add GitHub repository/live demo links to each project when available.
- Confirm the photo crop is the one you want to publish.
- Add a resume PDF if you want a resume download button.

## Deploy on GitHub Pages
1. Create a GitHub repository (for example `tanay-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Deploy on Netlify
Drag the extracted project folder (containing `index.html`) into Netlify's manual deploy area, or connect the GitHub repository.

## Notes
- The site is responsive and includes scroll reveal, a reading progress bar, animated ticker, mobile menu and subtle pointer effects.
- The contact button is intentionally a placeholder until a real email is added.
- Project cards describe the projects based on the details provided; add real source/demo links once available.
